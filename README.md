# VB.NET-Projects
# Visual Basic .NET Projects

Zbirka praktičnih vežbi u **Visual Basic .NET-u** (Konzolne i Windows Forms aplikacije).

---

## 🇷🇸 Srpski

### 🖥️ Konzolne aplikacije
* **`VB - Calculator.vb`** — Običan kalkulator (sabiranje, oduzimanje, množenje, deljenje).
* **`VB - GuessNumber.vb`** — Igra pogađanja broja uz tragove da li je traženi broj veći ili manji.
* **`VB - Login.vb`** — Provera korisničkog imena i lozinke.

---

### 🖼️ Windows Forms aplikacije (`/WindowsFormsSamples`)
1. **Trigonometrijski kalkulator** — Računa sinus i kosinus unetog ugla (koji u kodu preračunava u radijane za `Math.Sin` i `Math.Cos`) i prikazuje ih u `TextBox`-u.
2. **Brojač prelaza miša** — Broji koliko je puta kursor miša prešao preko dugmeta, uz dugme za resetovanje na 0.
3. **Kalkulator površine pravougaonika** — Računa površinu automatski čim uneseš brojeve i prikazuje rezultat u zasebnom `TextBox`-u (koristi `TextChanged` događaj).

---

## 🇺🇸 English

### 🖥️ Console Apps
* **`VB - Calculator.vb`** — Basic calculator (+, -, *, /).
* **`VB - GuessNumber.vb`** — Number guessing game with higher/lower hints.
* **`VB - Login.vb`** — Simple login check for username and password.

---

### 🖼️ Windows Forms (`/WindowsFormsSamples`)
1. **Trigonometric Calculator** — Calculates sine & cosine from an entered angle (converts to radians for `Math.Sin`/`Math.Cos`) and displays results in text boxes.
2. **Mouse Hover Counter** — Counts how many times the mouse cursor moves over a button, with a reset button.
3. **Rectangle Area Calculator** — Calculates area automatically as you type numbers and shows the result in a separate text box (using the `TextChanged` event).
